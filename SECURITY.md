# Security Policy

## Supported versions

Security fixes are applied to the latest published versions of the Santi020k Theme packages, extensions, and websites. Older releases are not maintained separately.

## Reporting a vulnerability

Please report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/santi020k/santi020k-theme/security/advisories/new). Do not open a public issue for an undisclosed vulnerability.

Include the affected package or surface, reproduction steps, impact, and any suggested mitigation. You can expect an initial response within seven days. Confirmed reports will be addressed privately before a coordinated disclosure when practical.

## Scope

Reports about repository code, release automation, published npm packages, editor or browser extensions, terminal installers, and the project websites are welcome. Vulnerabilities in third-party services should be reported to their respective maintainers.
