# VS Code gallery studio backdrops

AI-generated decorative artwork for the `/vscode/` screenshot gallery. The light studio scene and its dark companion share a 1536 × 1024 composition with matte curved folds at the edges and a quiet center.

These PNGs are raster masters. Astro exports lazy-loaded WEBP display images from them. Keep the actual editor captures in `packages/theme/assets/vscode/previews/` separate and unmodified; gallery links open those full-size originals.

The built-in imagegen tool generated `lavender-studio.png`; an imagegen edit using it as the reference generated `indigo-studio.png`. Prompts are recorded in `prompts.json`. This artwork is a presentation backdrop, not a theme screenshot or downloadable wallpaper.
